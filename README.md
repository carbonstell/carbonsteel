# سیستم درخواست قیمت و صدور پیش‌فاکتور
## شرکت کربن استیل شهباز

### نصب و اجرا

```bash
npm install
npm run dev
```

سپس برو به: http://localhost:3000

### ورود ادمین
- آدرس: /admin
- نام کاربری: admin
- رمز عبور: admin123

### نکته خیلی مهم در مورد داده‌ها
اطلاعات در پوشه `data` ذخیره می‌شود.
**هنگام آپدیت پروژه، پوشه `data` را پاک نکنید و جایگزین نکنید.**
